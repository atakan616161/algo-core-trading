Thanks for choosing to contribute to AlgoCore Trading! We appreciate your time and effort.

Guidelines:

- Check existing issues before opening a new one. Search for similar feature requests or bugs.
- When opening an issue, provide a concise title, steps to reproduce, expected vs actual behavior, and any relevant logs.
- Contributions should come as pull requests against the `main` branch. Create a feature branch, make changes, run tests, and open a PR describing the change.
- Keep changes focused and documented. Large or breaking changes should be discussed in an issue first.

Code style & tests:

- Use TypeScript/JavaScript consistent with the repository coding style.
- Run tests and linters before opening a PR.

Thanks — maintainers
